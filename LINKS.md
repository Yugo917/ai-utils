# AI Resources & Tools

## 📊 Benchmarks & Model Evaluation

* **[Can I Run AI](https://www.canirun.ai/)**  
  *Checks if your hardware (VRAM/RAM) can locally run specific AI models.*

* **[Artificial Analysis](https://artificialanalysis.ai/models)**  
  *An independent benchmark comparing speed, latency, cost, and overall LLM performance.*

* **[LiveBench](https://livebench.ai/)**  
  *A regularly updated LLM benchmark.*

* **[MTEB Leaderboard](https://huggingface.co/spaces/mteb/leaderboard)**  
  *A benchmark evaluating and ranking text embedding models across various tasks.*
